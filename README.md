## ✨ Features

- **🌙 Sleek Dark Theme:** Designed with a futuristic aesthetic palette featuring deep slate backgrounds and vibrant neon cyan/emerald accents.
- **⚡ Interactive Feedback Form:** Clean form with vanilla JavaScript validation providing instant feedback confirmation (*"Your response has been recorded"*).
- **📱 Fully Responsive:** Adaptive layout optimized for all devices ranging from mobile phones to widescreen desktops with a functional mobile menu toggle.
- **🎨 High-Quality Imagery:** Curated visuals powered by Unsplash depicting modern sustainable infrastructure and transit networks.

## 📂 Project Structure

```text
smart-city-website/
│
├── index.html       # Main structure and content layout

└── index.js         # Mobile menu toggle and feedback form submission handler
```

---

## 🚀 Getting Started

To run this project locally on your machine, follow these simple steps:

1. **Clone or Download** this repository.
2. Ensure all three files (`index.html`, `style.css`, and `index.js`) are in the **same directory**.
3. Open `index.html` in any modern web browser (Google Chrome, Firefox, Edge, or Safari).

## 💡 Tech Stack

- **HTML5:** Semantic architecture and structure.
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, and media queries.
- **Vanilla JavaScript:** DOM manipulation, event listeners, and interactive UI states.
- **FontAwesome & Google Fonts:** Modern iconography and typography (`Segoe UI`).
